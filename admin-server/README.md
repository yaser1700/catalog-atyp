# پنل مدیریت آزمایشی کاتالوگ تکنو یدک

این پوشه یک نمونهٔ جدا از کاتالوگ اصلی است. فایل `index.html` اصلی در این شاخه تغییر داده نشده است؛ نسخهٔ پشتیبان آن در `backups/index-original-2026-10-13.html` قرار دارد.

## وضعیت
- این کد برای آماده‌سازی و بازبینی آزمایشی است و هنوز به سایت عمومی وصل نیست.
- برای انتشار واقعی، یک سرور Node.js با فضای ذخیره‌سازی پایدار و پایگاه داده لازم است.
- رمز مدیر و کلید نشست باید فقط در متغیرهای محیطی سرور قرار گیرند؛ هرگز داخل GitHub یا فایل‌های HTML نگذارید.
- فایل اکسل مورد انتظار دارای ستون‌های «کد کالا» و «قیمت به ریال» است.
- قیمت عادی و قیمت تخفیفی جدا نگهداری می‌شوند؛ اکسل تخفیف نباید قیمت اصلی را بازنویسی کند.
- اگر یک کد در چند گروه باشد، همهٔ جایگاه‌ها شناسایی می‌شوند. اختلاف نام یا قیمت برای یک کد، هشدار می‌دهد و نباید خودکار یکسان‌سازی شود.

## پیش از هر انتشار
1. نصب وابستگی‌ها و اجرای آزمون‌ها در محیط آزمایشی.
2. ساخت پایگاه دادهٔ پایدار و حساب مدیر امن.
3. آزمایش فایل‌های اکسل معتبر/نامعتبر، کدهای تکراری، قیمت صفر/منفی و اختلاف قیمت بین گروه‌ها.
4. تأیید دستی نتیجهٔ پیش‌نمایش.
5. آزمون کامل نسخهٔ آزمایشی؛ فقط پس از تأیید صریح مدیر می‌توان دربارهٔ انتشار تصمیم گرفت.

هیچ اطلاعات محرمانه یا رمز عبوری را در این مخزن قرار ندهید.
