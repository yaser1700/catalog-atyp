# راهنمای اجرای پنل مستقل روی سرور ویندوز

> این سرویس در پوشه جداگانه `admin-server` اجرا می‌شود. فایل‌های `index.html` و `category.html` کاتالوگ عمومی را تغییر نمی‌دهد و در این مرحله هیچ اطلاعاتی به سایت عمومی ارسال نمی‌شود.

## ۱) پیش‌نیازها
- Windows Server 2019 یا جدیدتر (Windows 10/11 هم برای آزمایش قابل استفاده است)
- Node.js نسخه 22 LTS از سایت رسمی Node.js
- دسترسی مدیر برای نصب نرم‌افزار
- یک مسیر دائمی برای پایگاه داده و تصاویر، ترجیحاً خارج از پوشه موقت

پس از نصب Node.js، در PowerShell اجرا کنید:
```powershell
node -v
npm -v
```

## ۲) دریافت کد
از شاخه آزمایشی مخزن، پوشه `admin-server` را دریافت کنید:
https://github.com/yaser1700/catalog-atyp/tree/staging/admin-panel-baseline/admin-server

در PowerShell وارد همان پوشه شوید و اجرا کنید:
```powershell
npm install
```

اگر نصب `better-sqlite3` خطا داد، ابتدا نسخه رسمی Node.js 22 LTS را نصب/به‌روزرسانی کنید و دوباره `npm install` را اجرا کنید. خطای نصب را کپی کنید تا بر اساس همان خطا راهنمایی کنم.

## ۳) تنظیم متغیرهای محیطی
برای آزمایش می‌توان متغیرها را در همان پنجره PowerShell تنظیم کرد. رمز واقعی را در GitHub یا چت ارسال نکنید:
```powershell
$env:ADMIN_PASSWORD = "یک-رمز-طولانی-و-خصوصی-حداقل-۱۶-کاراکتر"
$env:SESSION_SECRET = "یک-رشته-تصادفی-خصوصی-حداقل-۳۲-کاراکتر"
$env:DB_PATH = "D:\\ATYP-Admin-Data\\admin.sqlite"
$env:PORT = "3000"
$env:NODE_ENV = "development"
npm start
```
مطمئن شوید پوشه `D:\\ATYP-Admin-Data` پیش از اجرا ساخته شده است. برای آزمایش محلی، نشانی `http://localhost:3000` را باز کنید.

## ۴) انتشار امن در شبکه
برای دسترسی از اینترنت، پورت برنامه را مستقیماً باز نکنید. ابتدا HTTPS با گواهی معتبر و reverse proxy (مانند IIS با ARR/URL Rewrite یا Caddy) راه‌اندازی شود؛ سپس تنظیمات نشست امن و `NODE_ENV=production` مطابق HTTPS آزمایش شود. فایروال ویندوز باید فقط پورت HTTPS را برای کاربران مجاز باز بگذارد.

## ۵) پیش از استفاده واقعی
- از فایل SQLite و پوشه تصاویر نسخه پشتیبان زمان‌بندی‌شده بگیرید.
- پنل هنوز به کاتالوگ عمومی وصل نیست.
- هرگز `.env`، رمز مدیر یا `SESSION_SECRET` را داخل مخزن GitHub قرار ندهید.
- پیش از انتشار عمومی، تست ورود، نشست، بارگذاری اکسل و پشتیبان‌گیری را انجام دهید.
